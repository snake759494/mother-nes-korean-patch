# 글꼴

글꼴 파일은 저장소와 릴리즈에 포함하지 않습니다. 패치 결과물에는 아래 글꼴로 그린 글자 이미지가 들어갑니다.

| 글꼴 | 쓰인 곳 | 라이선스 |
| --- | --- | --- |
| 갈무리7 (Galmuri7) | 모든 한글(8×8, 원래 크기 그대로, 확대·축소 없음) | SIL Open Font License 1.1 — https://github.com/quiple/galmuri |

갈무리7에서 「쯤」은 「좀」과 같은 모양이라 쌍지읒이 보이도록 한 글자만 따로 그렸습니다(`tools/build.py`의 `OVR`).
